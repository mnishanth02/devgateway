# ADR Governance Index

This index maps the accepted architecture decisions to interim accountability, implementation impact, and follow-up gates for Track 0 governance. It is a documentation-only control and does not enable production model, tool, retrieval, workflow, or deployment capability.

Sources: `AI-Platform-Proposal.md`, `docs\01-system-architecture-and-interfaces.md`, `docs\02-agent-workflows-tools.md`, `docs\03-knowledge-retrieval-evaluation.md`, `docs\04-technology-roadmap-operations.md`, and `docs\impl-plan\track-0-architecture-lock-implementation-setup.md`.

Named people can replace interim role owners during implementation. Track 0 cannot exit until named people or explicitly approved accountable roles are assigned.
